# Alejandro Nieto Rodriguez

I am a geospatial analyst in Toronto working on Earth observation, ecosystem monitoring, and spatial quality control. I use Python and Google Earth Engine to turn satellite imagery and geospatial data into reproducible change-detection, classification, and monitoring workflows.

My recent work has focused on Landsat and Sentinel-2 time series, land-cover mapping, wetland change, and practical GIS tools for production environments.

## Selected work

### [Kissimmee River Restoration](https://github.com/anietoro800/Kissimmee-River-Restoration)

Remote-sensing analysis of vegetation and surface-water trends during restoration of the Kissimmee River in Florida. The project uses Landsat imagery from 1985 to 2023, annual composites, NDVI and MNDWI trend maps, and site-level time-series checks.

[![Kissimmee River MNDWI and NDVI trend maps](https://raw.githubusercontent.com/anietoro800/Kissimmee-River-Restoration/main/analysis/fig1.jpg)](https://github.com/anietoro800/Kissimmee-River-Restoration)

### [Minimal Change Pixels](https://github.com/anietoro800/Minimal-Change-Pixels)

A Google Earth Engine workflow for identifying spectrally stable Landsat pixels with CCDC. Stable pixels can be used as candidates for transferring reference labels across a multi-decadal time series.
